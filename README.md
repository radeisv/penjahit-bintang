Penjahit Bintang (Stitch the Stars) — a puzzle-arcade game where you are a sky tailor. Stars fall from the night sky; drag the mouse to stitch stars of the pattern's kind into constellations before they fade, dodge the void meteors, keep your 3 lives, and finish all 5 levels to stitch the whole sky. Each level asks for a longer pattern in a different star kind, stars fall faster, and a rare white hope star restores a life. All art is procedural Canvas vector art and all sound is procedural Web Audio — no copied assets, no network.

## Controls

- Mouse drag: stitch stars (start on a star, drag through stars of the same kind)
- Space / P / Esc: pause and resume
- R: restart
- Click / Space / Enter: start, and restart from the win or game-over screen

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` directly from a static server — the game loads no network resources at all.
